---
title: Getting Started
description: Flash firmware onto a LIA board and pair it with the Meshtastic app.
---

This guide gets a LIA board running Meshtastic firmware and visible in the Meshtastic companion app. It assumes you already have an assembled board — see [Assembly](/LIA/docs/hardware/assembly/) if you're starting from bare PCBs.

## What you'll need

- A LIA board (see [Hardware](/LIA/docs/hardware/pcb/) for build files)
- A USB-C cable or a magnetic 4-pin connector (like [Seeed's T1000](https://www.seeedstudio.com/USB-Cable-Type-A-to-4P-with-magnetic-type-Black-1000mm-p-5977.html))
- The [Meshtastic Android or iOS app](https://meshtastic.org/docs/software/apps/) installed on your phone

## 1. Flash the firmware

LIA runs stock [Meshtastic](https://meshtastic.org/) firmware for the ESP32-S3 target, plus a LIA-specific `lia_v1` board variant layered on top that adds support for the mode switch, status LED, charger status, battery gauge, IMU, and text-command interface — the same `lia_v1` build is correct for both V1.0 and V1.1 boards (see [Building the Firmware](/LIA/docs/firmware/building-the-firmware/#which-variant)).

:::caution
The [Meshtastic Web Flasher](https://flasher.meshtastic.org/) only offers stock, generic ESP32-S3 firmware — it has no `lia_v1` target and doesn't know about LIA's board-specific peripherals, so it isn't usable here. Go straight to **[Building the Firmware](/LIA/docs/firmware/building-the-firmware/)** for the full build-and-flash procedure.
:::

:::caution
The board's mode switch has a third, OFF position that cuts power to the ESP32-S3 entirely (see [Power Management](/LIA/docs/firmware/power-management/)). USB/pogo power alone won't turn the board on if the switch is OFF — it only charges the battery. Make sure the switch is in either of its other two positions before connecting to flash or use the device over serial.
:::

:::tip
If the board doesn't show up as a serial port, install the [CP210x](https://www.silabs.com/developer-tools/usb-to-uart-bridge-vcp-drivers) or native USB CDC driver for your OS first.
:::

## 2. Pair with the app

1. Open the Meshtastic app and add a new device over Bluetooth.
2. Select your LIA device from the scan list.
3. Once connected, confirm it reports a GPS fix — see [GPS](/LIA/docs/firmware/gps/) if it doesn't.

:::tip
Set the device role to **Tracker** and note the node ID of the phone/node you want LIA to report to — LIA sends position broadcasts and text-command replies as direct messages to a single hardcoded target node, not a channel broadcast, so that node must be configured in the firmware before flashing — see [Meshtastic Configuration](/LIA/docs/firmware/meshtastic-configuration/) for exactly what's required and why.
:::

## 3. Confirm mesh connectivity

Send `HELP` as a direct message to the device. A reply listing the available commands confirms the LoRa radio, antenna, and firmware command handling are all working end-to-end — see [Meshtastic Configuration](/LIA/docs/firmware/meshtastic-configuration/) for the full command list.
