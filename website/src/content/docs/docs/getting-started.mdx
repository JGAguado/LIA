This guide gets a LIA board running Meshtastic firmware and visible in the Meshtastic companion app. It assumes you already have an assembled board — see [Assembly](/LIA/docs/hardware/assembly/) if you're starting from bare PCBs.

## What you'll need

- A LIA board (see [Hardware](/LIA/docs/hardware/pcb/) for build files)
- A USB-C cable or a magnetic 4-pin connector (like [Seeed's T1000](https://www.seeedstudio.com/USB-Cable-Type-A-to-4P-with-magnetic-type-Black-1000mm-p-5977.html))
- The [Meshtastic Android or iOS app](https://meshtastic.org/docs/software/apps/) installed on your phone

## 1. Flash the firmware

LIA runs stock [Meshtastic](https://meshtastic.org/) firmware for the ESP32-S3 target, plus LIA-specific configuration layered on top (see [Meshtastic Configuration](/LIA/docs/firmware/meshtastic-configuration/)).

<Tabs>
  <TabItem label="Web Flasher">
    <Steps>
    1. Connect the board.
    2. Open the [Meshtastic Web Flasher](https://flasher.meshtastic.org/) in Chrome or Edge.
    3. Select the matching ESP32-S3 target and click **Flash**.
    </Steps>
  </TabItem>
  <TabItem label="CLI (meshtastic-python)">
    <Steps>
    1. Install the CLI: `pip install meshtastic`
    2. Put the board in bootloader mode (hold **BOOT**, tap **RESET**, release **BOOT**).
    3. Flash: `meshtastic --port <PORT> --flash firmware.bin`
    </Steps>
  </TabItem>
  <TabItem label="LIA custom build (recommended)">
    LIA has `lia_v1`/`lia_v2` Meshtastic board variants with full support for the mode switch, RED LED, charger status, battery gauge, and (on `lia_v1`) the IMU and text-command interface — this is the build that actually knows about LIA's board-specific behavior, rather than treating it as a generic ESP32-S3. See [Building the Firmware](/LIA/docs/firmware/building-the-firmware/) for the build/flash procedure.
  </TabItem>
</Tabs>

> [!TIP]
> If the board doesn't show up as a serial port, install the [CP210x](https://www.silabs.com/developer-tools/usb-to-uart-bridge-vcp-drivers) or native USB CDC driver for your OS first.

## 2. Pair with the app

1. Open the Meshtastic app and add a new device over Bluetooth.
2. Select your LIA device from the scan list.
3. Once connected, confirm it reports a GPS fix — see [GPS](/LIA/docs/firmware/gps/) if it doesn't.

> [!TIP]
> Set the device role to **Tracker** and add a private channel named exactly `Test` before expecting position broadcasts or any of LIA's text commands to work — see [Meshtastic Configuration](/LIA/docs/firmware/meshtastic-configuration/) for exactly what's required and why.

## 3. Confirm mesh connectivity

Send `HELP` on the `Test` channel (or as a direct message to the device). A reply listing the available commands confirms the LoRa radio, antenna, and firmware command handling are all working end-to-end — see [Meshtastic Configuration](/LIA/docs/firmware/meshtastic-configuration/) for the full command list.
