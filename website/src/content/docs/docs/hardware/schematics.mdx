## Reference designs

Some subcircuits (battery charging, buck-boost regulation) are adapted from published reference designs. Source references are kept locally under `hardware/schematics/references/`, which isn't published in the repository (third-party datasheets/reference material, not LIA's own original work).

:::caution
The schematic is a work in progress and has not yet been through a formal design review. If you build from it, double-check power and charging circuitry before connecting a battery.
:::

See also: [PCB](/LIA/docs/hardware/pcb/) and [BOM](/LIA/docs/hardware/bom/).
